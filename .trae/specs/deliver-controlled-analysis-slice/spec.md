# 受控分析切片：完整文件列求和

2026-10-29；基线 `main @ 0aca6ee`。承接用户“下一步迭代”和继续执行指令。

## 为什么

现有文件分析仅提供最多 20,000 字符的预览，无法证明统计覆盖完整文件。
本轮先交付无需模型的确定性后端闭环，作为后续聊天、图表和报告的数值来源。

## 本轮变化

- 新增 `POST /api/files/{file_id}/statistics`，只接受 `{"column":"列名"}`，
  白名单指标固定为 `sum`；`?download=true` 下载同一结果 JSON。
- 从当前主体拥有的有效受管文件读取完整字节，复用根目录、类型、大小和 SHA 校验。
- 输出完整行数、各列类型/缺失数、重复行数、选定列有效值/范围/精确和、
  固定模板解释、来源 UUID/SHA、参数、版本及 canonical 结果摘要。
- 不持久化统计产物、不缓存；重试重新验证当前文件。已下载副本属于请求时快照，
  删除源文件不会撤回用户已取得的副本，后续请求必须拒绝失效来源。

## 范围与影响

涉及 `managed_file_service.py`、`routes/managed_file.py`、独立确定性计算模块、
行为回归及 README/CHANGELOG/roadmap。本轮不改数据库结构或上传策略。
原预览接口保持；聊天工具接入和 REST 回答缓存 REV-A03 留待独立后续迭代。
不将本轮后端闭环描述为完整 Chat UI 分析、生产放行或真实模型效果验收。

## 新增要求

### 要求：明确的表格与数值合同

- CSV 必须有非空、不重复的列名、至少一行数据、每行列数一致；保留现有公式拒绝。
  JSON 仅接受非空对象数组，各行键集合一致，标量单元格；拒绝重复键、非有限数值、
  嵌套结构和不明确的表结构。JSON 列按名称排序，CSV 保留表头顺序。
- 数值允许有限十进制；最多 38 位有效数字、38 位整数和 18 位小数。
  数值文本最多 128 字符；使用 Decimal 和足够精度精确累计，输出十进制字符串。
  JSON 可表达负数；CSV 继续遵守原有不接受负号开头单元格的摄取合同。
- 空字符串和 JSON null 算缺失；不自动去空白、不把 bool/任意文本当数值。
  目标列非数值整次拒绝；全缺失拒绝；有效零值允许。保留重复行参与求和并明确警告。
  单位固定“未指定”，不推断币种，不静默四舍五入。
- 最大 5 MiB（同时受上传配置限制）、50,000 行、64 列、250,000 单元格、
  列名 128 字符；解析和遍历设置 5 秒计算期限，超限不返回部分统计。
  同步有界计算在 FastAPI 工作线程执行；取消不产生后台持久产物。

#### 场景：完整文件求和与下载

- 当有效文件超过预览上限、尾部含额外数值时，结果必须覆盖尾部，与独立参考一致。
- 当重复请求相同来源和参数或下载时，JSON 业务内容及结果摘要一致。
- 摘要为移除 `result_sha256` 后排序键、紧凑分隔、ASCII JSON 的 SHA-256。
  解释从同一统计值生成，数值不得再由模型重新计算。

### 要求：当前文件的身份与生命周期

- 路由和服务均验证当前权限，owner 来自认证，不接受请求体中的 owner/path/metric。
- 每次重新检查有效期及字节完整性；跨用户、管理员访问他人文件、删除和过期统一 404。
- 文件漂移、存储路径异常、非普通文件等沿用稳定错误；不返回宿主路径或原始数据行。
- 响应设置 `Cache-Control: no-store`；下载名仅包含服务端规范 UUID。

#### 场景：重试时来源已变化

- 首次成功后文件删除、过期或字节漂移，再次统计/下载必须重新拒绝，
  不返回上一次成功结果。并发独立请求不得共享可变累计状态。
