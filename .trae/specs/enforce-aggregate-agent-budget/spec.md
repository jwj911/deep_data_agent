# Run 合计预算门禁

用户授权：2026-10-28「继续完成 Hosted、合计预算和恢复等门禁验收」。

同一次顶层调用建立一个服务端账本，父图、内联 general-purpose 子图、
摘要与 SDK 重试共享计数。默认模型请求不超过 8 次、工具执行不超过 12 次，
不扩大既有批准上限。模型在 HTTP 请求发送前预留；工具在执行前预留。
失败请求与失败工具同样耗用预算；拒绝的请求不产生对应网络或工具副作用。

账本仅存在于稳定的执行 Context/Task，不接受客户端参数，不写入 checkpoint。
并行分支原子预留，不同 run、owner 和复制图不串账。摘要或 SDK 吞掉拒绝时，
顶层仍必须失败，保持既有稳定错误码及不缓存失败结果。取消和 deadline
保留既有等待清理、单次租约释放合同。仅记录计数与限额，不记录正文或身份。

general-purpose 保留默认文件工具、摘要、补齐工具结果及应用工具，通过公开的
CompiledSubAgent 接口绑定服务端递归限额；不开放远端或后台子 Agent。

验收需实际工厂图覆盖四调用面、copy/with_config、父子、内置工具、摘要、
SDK 重试、并行、双 owner、取消和超时。第 9 个模型请求和第 13 个工具执行
在副作用前拒绝；HTTP 替身与独立计数核对总账。Hosted 仅认可目标提交对应结果。
