# 合计预算验收记录

2026-10-28；当前工作树，未提交、未取得本轮 Hosted 结果。

实现采用独立 `RunBudget`，在现有稳定执行 Context/Task 的租约作用域内创建。
HTTPX 请求钩子在 SDK 每次实际请求前预留模型额度，父/子摘要共用同一个
ChatOpenAI 和钩子；工具 middleware 在父、内联 general-purpose 的所有工具
执行前预留。客户端不可提供账本，复制图保留既有 lease/checkpoint/store 合同。
并行分支原子计数，拒绝状态保持到顶层，摘要或 SDK 包装拒绝不能造成成功缓存。
工具策略版本由 3 变为 4，使旧策略的缓存结果不继续复用。

本机 Python 3.12.9；DeepAgents 0.7.5、LangChain 1.3.15、
LangChain Core 1.5.4、langchain-openai 1.4.3、httpx 0.28.1。
全部调用使用离线 HTTP 替身，无真实模型或搜索请求。

| 验收 | 观测结果 |
| --- | --- |
| 实际默认工厂负控 | 只有主图 middleware 时，父 2 + 子 8 = 10 个模型请求；父 task 1 + 子 19 = 20 个工具调用 |
| 合计模型拒绝 | 原图/copy/with_config × invoke/ainvoke/stream/astream：独立 HTTP 接收计数为 8，第 9 个请求不发送 |
| 合计工具拒绝 | 同上；父 task 与子内置 `ls` 共预留 12，第 13 个工具执行前拒绝 |
| 默认摘要 | 保留实际默认 170k token 触发与六消息 tail；限额 1 时摘要请求执行、主请求拒绝；限额 2 时两次请求成功 |
| SDK 重试 | 实际 HTTP 500 重试；限额 1 拒绝第二次请求，限额 2 实际接收两次并成功 |
| 并行与双 owner | 两个 owner、每个 parent 并行启动两个 child；各自独立账本、各接收 8 个请求，无漏账/串账 |
| 工作线程竞争 | 64 个竞争预留中恰好 12 个工具获准；被分支吞掉的拒绝在 scope 退出仍拒绝 |
| 子图递归 | 服务端限额 4，客户端 9999 不生效；子图递归拒绝保持单次租约释放 |
| 实际服务失败缓存 | 模型/工具拒绝均不写成功缓存，外层服务与图复用一次 lease |
| 关闭/取消/超时 | 跨 Task 消费和关闭，执行端清理仍访问相同账本；清理完成后释放一次、调用者无残留账本 |
| 计数事件 | 成功父子 run 的真实 HTTP 3 次 / task 1 次与安全事件一致，仅计数/限额/结果，无正文或身份 |
