# 稳定运行时与依赖锁门禁

授权：2026-10-28「继续完成 Hosted、合计预算和恢复等门禁验收」。

采用官方仍维护的 LangGraph API minor，在 Python 3.12 下验证实际工厂、
图复制、四调用面、第一方认证、租户隔离、预算、退出清理和持久恢复。
升级不改变业务权限；不将旧 pickle 跨运行时兼容性视为默认成立。

`requirements.in` 声明直接依赖；`requirements.txt` 是包含传递依赖、
平台条件及包哈希的唯一安装锁。Windows、Ubuntu Hosted 与 Docker 均
使用该锁并强制哈希检查。验证锁覆盖全部依赖且已安装版本匹配。
版本过期检查在有网络的发布门禁读取官方元数据，不静默升级。

本机旧依赖的通过结果保留为修复回归证据；新锁需要独立完整测试和
当前源码容器/HTTP/浏览器证据。最终 Hosted 必须对应当前分支精确 SHA。
