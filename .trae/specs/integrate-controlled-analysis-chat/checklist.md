# 验收

- [x] 1. 上一轮统计改动与无关用户改动保留，基线、环境和本轮证据分开记录。
- [x] 2. 模型可见工具参数只有 file_id、column；owner、路径、表达式和预算覆盖均被拒绝。
- [x] 3. 列名或多附件选择不明确时请求澄清，不默认计算首列/首文件。
- [x] 4. 工具通过服务端主体与当前角色授权；双 owner、管理员越权和失效用户负控通过。
- [x] 5. 完整 CSV/JSON 工具结果与 REST、独立数值参考一致，预览外尾部参与计算。
- [x] 6. 成功/错误外层协议明确，canonical 数据和 hash 保持，错误不携带成功 payload。
- [x] 7. 父子图、并行分支、四调用面和复制图共享限额，第 13 次工具执行前拒绝读取。
- [x] 8. 统计等待不直接阻塞异步事件循环，适配容量有界，取消/超时无迟到成功或缓存。
- [x] 9. 正常、失败、关闭流和取消后的身份清理与单次租约释放保持。
- [x] 10. 卡片关联真实 tool_call_id；普通文本、合成消息、损坏 JSON 和未知版本不伪装成功。
- [x] 11. 数值字符串精度不变，质量警告、单位、固定解释及来源字段与 canonical 结果一致。
- [x] 12. 隐藏工具详情仍可见统计卡片，流式更新和重复消息不生成重复卡片。
- [x] 13. 卡片键盘操作、错误文字、窄屏和长数值可用，动态文本不作为 HTML 或任意 URL。
- [x] 14. 下载仅请求固定 REST Origin，沿用 JWT/请求 ID；模型地址和额外目标不可用。
- [x] 15. 下载前比对来源、参数、版本与结果 hash，一致才交付 JSON。
- [x] 16. 删除、过期、漂移及版本变化后的下载不回退旧结果，历史卡片仍标为计算时快照。
- [x] 17. 下载请求禁重、失败重试、Blob 释放、切线程/退出中止和迟到结果隔离通过。
- [x] 18. REST 文件引用请求绕过回答缓存读写，旧策略命名空间不再命中且未清全库。
- [x] 19. 无显式引用但实际执行文件/其他工具的 run 不写缓存，父子、工作线程及并行不漏记。
- [x] 20. 未知观察状态、工具失败、预算拒绝、取消、超时和部分结果不缓存。
- [x] 21. 普通零工具问答保持新策略缓存及主体隔离，独立搜索缓存行为未被误改。
- [x] 22. 缺失工具结果按 ID 精确补齐，真实/乱序/部分结果保持，重复补齐幂等且不伪造成功。
- [x] 23. 缺失工具调用 ID 不构造空 ID 消息，不合法续发时保留输入并提示恢复/重试。
- [x] 24. 公开样本的实际聊天、卡片、下载与失败重试通过浏览器行为验证；直接 REST 不替代聊天证据。
- [x] 25. 全后端、前端四门禁、发布契约、迁移和差异检查通过，文档更新且生产/Hosted 缺口如实保留。
