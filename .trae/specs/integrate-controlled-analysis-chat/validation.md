## 实现合同

- `analyze_file_statistics` 仅接受规范 UUID `file_id` 和明确 `column`，
  指标固定 `sum`。服务端活动身份重新查询当前用户/角色，每次复核文件
  owner、有效期、路径、大小与 SHA，原样返回现有 canonical payload。
- 父图、子图及并行工具保持同一 run 模型 8 次、工具 12 次预算。
  统计工具每进程最多 4 个在途 worker；取消后的同步工作仍占槽，
  实际完成才释放，不形成无界队列。五秒仅是解析/遍历检查期限。
- 卡片只匹配真实工具调用及 `ToolMessage`，保持十进制字符串精度，
  显示行数、质量、来源及“计算时快照”，隐藏通用工具详情不隐藏卡片。
- 下载固定访问 FastAPI Origin，重新校验来源并比对完整结果后才交付；
  删除、过期、漂移或版本变化阻止新下载，旧卡片保留。请求禁重，
  切线程、登出与卸载中止并丢弃迟到结果。
- REST 使用 `agent:zero-tool-v1:` 命名空间。显式文件引用绕过读写；
  其他请求只有服务端观察完整且零工具成功时写入。未知、工具型、失败、
  取消、超时及部分结果不缓存。独立搜索缓存和 LangGraph 历史分别保留其合同。
- 缺失工具响应按调用 ID 补明确未完成错误，真实响应保留且补齐幂等；
  缺失调用 ID 时阻止非法续发并保留用户输入及附件。
