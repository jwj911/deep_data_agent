# 验收清单

- [x] 合法的 32 位小写十六进制 `X-Request-ID` 在 FastAPI 响应头、Agent 错误
  详情和结构化事件中保持一致。
- [x] 缺失、大小写错误、长度错误或含非法字符的请求 ID 被替换，原值不进入日志。
- [x] FastAPI 全路由记录路由模板、方法、状态码、结果与耗时，不记录请求体、
  查询参数、客户端 IP、用户名、邮箱或消息正文。
- [x] CORS 允许并暴露 `X-Request-ID`，既有来源白名单与凭据策略不变。
- [x] 前端 REST 请求发送请求 ID，失败时可取得响应头中的诊断 ID。
- [x] LangGraph 新提交、重试与人工中断处理均在 `configurable` 和 `metadata`
  中携带请求 ID。
- [x] Agent、缓存和工具可从 FastAPI 或 LangGraph 运行配置绑定同一请求上下文。
- [x] 日志为单行 JSON，包含 schema、UTC 时间、级别、服务、logger 和事件名。
- [x] 结构化字段只允许固定低基数键和值类型，未知字段和非标量值不会进入输出。
- [x] 普通消息、事件字段、异常和诊断报告中的凭据、Token、密码及连接串均被
  `[REDACTED]` 替代。
- [x] HTTP、缓存、Agent、模型和工具关键生命周期均有开始、完成或失败事件。
- [x] 健康检查不依赖 JWT、模型或搜索凭据，不触发 Agent，并可在报告中折叠。
- [x] 文件日志使用明确的大小与备份数量轮转，Docker 日志也具有大小和文件数
  上限。
- [x] 诊断 CLI 仅由人工执行，支持按请求 ID 过滤以及标准输出或显式输出文件。
- [x] 诊断时间线按新到旧排序，高频健康检查不逐条占据时间线。
- [x] 报告汇总请求数、HTTP 错误率、平均/最大/P95 延迟、缓存降级和模型失败。
- [x] HTTP 5xx、缓存降级和模型失败产生明确告警信号，但不会自动外发通知。
- [x] 无效 JSON 行被计数并跳过，错误信息不回显原始日志内容。
- [x] `.env.example`、Compose、README、Roadmap 与 CHANGELOG 说明存储、保留、
  脱敏、人工触发和外部平台延期边界。
- [x] 后端全量测试和 `isort --check-only` 通过。
- [x] 前端 typecheck、零警告 Lint、格式检查和生产构建通过。
- [x] Compose 解析、发布契约、凭据扫描和 `git diff --check` 通过。
- [x] 测试、诊断样本和提交中不包含真实凭据、原始业务数据或构建产物。
