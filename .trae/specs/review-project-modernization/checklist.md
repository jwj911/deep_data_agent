# 验收清单

以下 25 项验证复审交付质量。运行检查若缺少条件，对应检查点要求如实记录缺口，
不表示该运行能力已通过验收。

- [x] 1. 记录正式复审日期、完整 HEAD、分支和工作区状态，来源为本轮实际命令。
- [x] 2. 既有规格完成度已核对，历史验收、当前实现与本轮证据明确区分。
- [x] 3. 当前业务目标及旧 Roadmap 决策已读取，整体判断说明短板和应保留的设计。
- [x] 4. Python、Node、pnpm、Docker 和相关环境版本已记录，环境不匹配有明确说明。
- [x] 5. 后端测试、isort、发布契约、Alembic 与 Compose 检查有实际结果或具体缺口。
- [x] 6. 前端类型、零警告 Lint、格式与构建有实际结果或具体缺口，生成物处理已核对。
- [x] 7. Hosted 与容器证据关联目标源码，未用历史 CI、旧镜像或 healthy 状态替代。
- [x] 8. 覆盖真实请求链、两个 Agent 入口、状态来源、模块接口及生命周期。
- [x] 9. 覆盖身份、RBAC、owner、固定来源、错误响应与跨租户边界。
- [x] 10. 覆盖文件、缓存、资源预算、迁移与恢复，历史 `AUD-*` 状态已重新核验。
- [x] 11. 核查 DeepAgents 默认工具、子 Agent、上下文、图包装与 middleware 的实际行为。
- [x] 12. 覆盖流式事件、取消/重试/中断、历史、附件、图表与静态部署的前端行为。
- [x] 13. 覆盖 CI、镜像、配置、测试盲区和 `utils/` 的真实引用及发布归属。
- [x] 14. 版本判断区分声明、锁定和实际安装，官方来源包含获取日期及适用范围。
- [x] 15. 安全公告与支持期限核对具体版本和部署模式，资料冲突或单源限制如实保留。
- [x] 16. 更新建议区分必要补丁、稳定迁移和可选能力，具备兼容风险与回归门槛。
- [x] 17. 分析能力沿输入、质量、计算、图表、溯源报告和产物获取逐环核对。

- [x] 19. 评测建议有任务集、成功标准、失败分类与版本记录，工程测试未冒充真实效果。
- [x] 20. 条目 ID 唯一、类型清晰，证据链接行号有效且单处范围不超过 100 行。
- [x] 21. 每条有效发现有影响、建议、依赖和验收条件，纯风格、猜测和重复项已排除。
- [x] 22. 两个独立验证者覆盖全部候选，确认矩阵、反证、分歧与最终处理可追溯。
- [x] 23. Roadmap 解释旧候选调整，优先迭代具有最小范围、收益依据、依赖与停止条件。
- [x] 24. 问题映射完整，两份 Mermaid 图与文字一致，生产门禁和业务前置没有混淆。
- [x] 25. 分析、规划、变更记录及必要指南状态一致，适用文档检查通过，无敏感原文或越界修改。
