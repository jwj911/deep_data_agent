# 全域备份与独立恢复门禁

授权：2026-10-28「继续完成 Hosted、合计预算和恢复等门禁验收」。

Compose 持久化 MySQL、LangGraph 主 thread/checkpoint/store 目录和受管文件。
备份须在入口停止写入、所有 Agent run 完成且后端正常关闭之后进行；
MySQL 使用一致逻辑导出，两个文件域分别归档。固定清单记录来源运行时、
源码、迁移版本、时间及各域 SHA-256，任一域缺失或摘要不符拒绝恢复。

恢复目标必须是独立新建 MySQL 和空文件卷。恢复前核验清单和全部归档，
恢复后核对用户/角色、REST 会话及消息、file metadata/字节摘要、LangGraph
thread/state/history/store，以及跨用户/管理员、删除、过期、篡改拒绝行为。
主历史中的 UUID 引用必须仍指向同 owner、同字节版本。

演练只写隔离合成 canary，不触碰开发或生产数据。恢复成功后允许重启写入；
失败目标保持停写。记录实际备份点、最新确认写入、恢复耗时和数据一致性，
不把同容器 restart、周期 flush、Redis 恢复或 MySQL 单域导出当作全域恢复。
Redis 缓存/限流/租约是可重建保护状态，恢复目标使用空 Redis，不恢复活动租约。

该迭代建立人工停写快照和可重复恢复门禁。自动备份、异地加密保留、生产
LangGraph 部署、灾难检测/切换和长期 RPO/RTO 承诺仍须另有实际运营证据。
